# Early Industrial Machine Failure Prediction

## Project Description

This project predicts industrial machine failures using cost-sensitive machine learning algorithms and the AI4I 2020 Predictive Maintenance dataset.

## Technologies Used

* Python
* Pandas and NumPy
* Scikit-learn
* Matplotlib and Seaborn
* Google Colab

## Machine Learning Models

* Logistic Regression
* Decision Tree
* Random Forest
* Cost-Sensitive Random Forest

## Dataset

The project uses the AI4I 2020 Predictive Maintenance dataset (`ai4i2020.csv`).

## Project Files

* `machine_failure_prediction.ipynb` — Complete Python code, model training, evaluation, graphs, and predictions.
* `ai4i2020.csv` — Dataset used for training and testing.

## How to Run

1. Open the notebook in Google Colab.
2. Upload `ai4i2020.csv` to the Colab session if requested.
3. Run the notebook cells from top to bottom.

## Result

The Cost-Sensitive Random Forest model achieved approximately 98.7% accuracy and 66.2% recall for machine failures in the test dataset.
